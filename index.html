Lunex Linux Installer

Automated script to install, update, and manage Lunex on Linux via Wine.

Install / Update

Run this command in your terminal:

bash <(curl -sSL https://lukebrotha.github.io/Lunex-OL/lunex.sh)


Uninstall

To remove Lunex and clean up files:

REMOVE=1 bash <(curl -sSL https://lukebrotha.github.io/Lunex-OL/lunex.sh)
